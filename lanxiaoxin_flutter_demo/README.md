# 蓝心同行 Flutter 主聊天页 Demo

这是一个纯 Flutter 高保真 UI Demo，用于展示“蓝心同行 / 蓝小心”的 AI 旅行搭子主聊天页面。

特点：
- 不依赖网络图片、不需要后端。
- 背景、路线、定位点、城市轮廓、蓝小心角色均使用 Flutter 绘制。
- 大量使用 Stack / Positioned / BackdropFilter / ClipRRect / CustomPainter / LinearGradient / BoxShadow。
- 重点呈现蓝白清爽、轻科技、二次元旅行搭子、磨砂玻璃拟态风格。

运行方式：
1. 新建 Flutter 项目，或直接解压本包。
2. 在项目根目录执行 `flutter pub get`。
3. 执行 `flutter run`。
4. 建议使用 Android/vivo 或 9:19.5 竖屏模拟器预览。

说明：
当前蓝小心是 Flutter 矢量 Mock 角色，便于无素材直接运行。正式参赛版可以将角色层替换为 Live2D、Spine、Rive 或透明 PNG 序列帧。

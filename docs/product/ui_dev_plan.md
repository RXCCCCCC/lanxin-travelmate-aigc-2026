# Flutter UI 开发计划（前端优先，五轮一次性完成）

## 1. 目标

按 `开发路线(ai看).md` 继续开发，先交付“用户可直接看到”的完整 App 前端页面，全部使用本地 Mock，不依赖真实后端。你在整体审阅 UI 无问题后，再继续接 FastAPI/LangGraph。

## 2. 工程与入口

- 工程位置：`apps/mobile/`
- App 名称：`lanxin_travelmate`
- 默认模式：游客模式直进首页
- 底部 Tab：4 个（首页、规划、旅拍、设置）
- 聊天页：不做独立 Tab，从首页进入
- 复盘入口：首页快捷入口 + 规划页尾部

## 3. 风格基准

- 参考实现：`lanxiaoxin_flutter_demo/`
- 视觉参考：`project/img/ui/页面风格参考图.png`
- 文案与风格：`project/img/ui/页面风格参考提示词.md`
- 蓝小心素材：`project/img/`（文件名即状态）

## 4. 五轮任务

### Round 1｜工程骨架
- 创建 Flutter 工程结构与主题 tokens
- 实现底部 4 Tab + 基础路由
- 实现游客模式默认进入首页

### Round 2｜首页蓝小心空间
- 蓝小心上半屏 70% 展示区
- 状态机切换本地素材
- 下半屏聊天入口、快捷入口、主动对话卡片

### Round 3｜聊天页
- 文字输入 + Mock 回复
- 记忆胶囊卡片、规划卡片、提醒卡片
- 卡片跳转与键盘适配

### Round 4｜记忆 + 画像
- 记忆胶囊列表与详情
- 保存范围：长期/本次/临时/不记忆
- 用户画像结构化页

### Round 5｜规划 + 旅拍 + 复盘 + 设置
- 规划时间轴、理由、风险提示
- 旅拍候选网格与文案入口
- 复盘卡与新增记忆展示
- 设置占位（人格、主动程度、同步策略、通知）

## 5. 验收标准

- `flutter run` 可启动并完成全部页面切换
- 竖屏 390~412 稳定
- 蓝小心图片完整展示
- 闭环可走通：记忆→规划→提醒→复盘

# 答辩 PPT 大纲

> 用途：给队友快速制作答辩 PPT。截图、队伍信息、真实 Key 演示结果和最终视觉风格必须人工替换确认。

## 第 1 页：作品标题

- 标题：蓝心同行
- 副标题：懂你的全旅程 AI 旅行搭子
- 关键词：个性化记忆、主动陪伴、真实工具链、旅行复盘
- 人工补充：队伍名称、成员、学校/单位、比赛组别。

## 第 2 页：问题与机会

- 旅行 App 常把规划、导航、拍照、复盘拆散，用户需要反复切换。
- 普通 AI 聊天只能生成一次性攻略，难以记住偏好、处理中途变化或沉淀复盘。
- 蓝心同行的目标是把“旅行前、中、后”做成连续陪伴闭环。

## 第 3 页：产品闭环

展示 6 步流程：

1. 聊天提出需求。
2. 用户确认记忆胶囊。
3. 生成个性化规划。
4. 旅行中主动提醒。
5. 旅拍候选与盲盒任务。
6. 旅行复盘与下次建议。

建议配图：App 六个页面截图，参考 `docs/handoff/demo-evidence-pack.md`。

## 第 4 页：核心创新

- 记忆可控：长期/本次/临时/不记忆，敏感信息显式确认。
- 规划可解释：画像匹配、风险提示、外部工具状态可见。
- 陪伴可主动：时间、位置、天气、行程节点和状态触发，带冷却机制。
- 复盘可沉淀：路线、照片、任务、提醒和状态变化进入下一次旅行建议。
- 降级可信：未配置真实 Key 时明确 fallback/unconfigured，不伪装真实数据。

## 第 5 页：技术架构

使用 `docs/handoff/demo-evidence-pack.md` 的系统架构图。

讲解点：

- Flutter Android App 负责页面、端侧 Drift、Android MethodChannel。
- FastAPI 提供统一业务 API、审计、同步和数据持久化。
- LangGraph TravelMate Agent 串联 19 个节点。
- 模型 Provider 和工具 Provider 都要求结构化输出、schema 校验和可解释 `toolTrace`。

## 第 6 页：Agent 设计

使用 `docs/handoff/demo-evidence-pack.md` 的 Agent 主链路图。

讲解点：

- 记忆抽取、规划、旅拍文案、复盘和聊天回复均有结构化 schema。
- schema 失败或 Provider 未配置时写入 `toolTrace`，并走明确降级。
- 审计日志记录 provider、scenario、fallback、错误类型和脱敏摘要。

## 第 7 页：真实数据与设备能力

- 后端：用户、记忆、画像、旅程、提醒、照片、复盘、模型日志、工具日志、同步记录。
- 外部工具：高德天气、POI、步行/驾车/公交/混合路线。
- Android/vivo：相册、相机、定位、麦克风、系统语音识别、TTS、系统通知。
- 端侧：Drift SQLite、本地同步队列、冲突检测、撤销云端同步。

人工补充：真实 Key 和真机验收状态。

## 第 8 页：隐私与可信

- 不自动保存敏感记忆，敏感/个人候选需要用户确认。
- 照片候选不上传或保存设备本地 URI/路径。
- 支持导出记忆、清空记忆、清空当前旅行、撤销云端同步。
- 模型和工具审计日志脱敏，不输出密钥、Token、密码或完整用户原文。
- 多人协调默认隐藏成员敏感偏好原文。

## 第 9 页：Demo 演示路径

使用 `docs/handoff/demo-script.md`：

1. 输入“周末想去重庆两天，不想太累，喜欢夜景，我不吃香菜”。
2. 确认记忆。
3. 查看规划和外部数据状态。
4. 触发主动提醒。
5. 登记旅拍候选并完成盲盒任务。
6. 生成复盘。
7. 展示审计日志。

人工补充：真实录屏二维码或视频链接。

# 蓝心同行当前作品主链路视频脚本

> 目标：录制一条能完整展示当前仓库已有功能的演示视频。主线是“提出旅行想法 -> 记忆确认 -> 个性化规划 -> 主动提醒 -> 旅拍/盲盒 -> 旅行复盘 -> 隐私与可信降级”。建议成片 5 到 7 分钟；如果比赛要求 3 分钟，可按文末压缩表执行。

## 录制前准备

优先使用公网 API：`https://api.rxcccccc.icu`。

录制 APK 或 `flutter run` 时传入：

```powershell
--dart-define=API_BASE_URL=https://api.rxcccccc.icu
```

如果公网服务不可用，切换本地后端：

```powershell
cd services/api
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
```

真机使用：

```powershell
flutter run --dart-define=API_BASE_URL=http://<电脑局域网IP>:8000
```

推荐统一使用广州两日游，便于和国内真实天气、POI、路线匹配：

```text
周末想去广州两天，不想太累，喜欢夜景，我不吃香菜，预算别太高。
```

准备 2 到 3 张可公开展示的旅行照片。不要展示密钥、Token、私人位置、身份证明或未授权人像。

## 镜头 1：开场和首页第一印象

时间：20 秒；3 分钟版压缩到 10 秒。

画面：手机冷启动 App，展示开屏动画，点击“开始我们的旅行吧!!!”，进入首页。停留在蓝小心立绘、天气条、状态抽屉、首页直聊、底部导航。

旁白：

“蓝心同行是一个面向移动出行场景的全旅程 AI 旅行搭子。它不是只回答问题，而是从旅行前的需求理解、旅行中的主动陪伴，到旅行后的复盘沉淀，形成一个连续闭环。首页里的蓝小心会随着对话、行程、提醒和任务改变状态。”

屏幕重点：蓝小心形象、陪伴/纯净模式、当前旅程、天气、消息、聊天历史、首页直聊。

## 镜头 2：自然语言提出旅行需求

时间：45 秒；3 分钟版压缩到 25 秒。

操作：在首页直聊或纯净模式输入：

```text
周末想去广州两天，不想太累，喜欢夜景，我不吃香菜，预算别太高。
```

等待蓝小心回复，展示思考态和回复内容。

旁白：

“用户不用先填复杂表单，只要像和朋友聊天一样说出目的地、偏好和约束。后端 Agent 会同时处理角色化回复、记忆候选、行程意图和工具调用上下文。这里我提到了广州、两天、慢节奏、夜景、忌口和预算。”

屏幕重点：用户消息右对齐、蓝小心思考态、蓝小心回复、规划或下一步入口。

如果看到 fallback 或 unconfigured，旁白补一句：

“这里展示的是系统的可信降级边界，真实 Provider 未返回时不会伪装真实数据。”

## 镜头 3：记忆胶囊

时间：50 秒；3 分钟版压缩到 30 秒。

操作：

1. 找到候选记忆，如“喜欢夜景”“不想太累”“不吃香菜”“预算别太高”。
2. 将“喜欢夜景”保存为长期记忆。
3. 将“不想太累”保存为本次旅行记忆。
4. 将“不吃香菜”保存为长期记忆，或展示可以选择“不记忆”。
5. 进入记忆页，展示可查看、编辑、删除。

旁白：

“记忆是蓝心同行和普通攻略工具最大的差异之一。但它不是后台偷偷保存。每条记忆都需要用户确认，可以选择长期、本次、临时或不记忆。用户后续可以随时编辑和删除。”

屏幕重点：记忆范围选择、记忆卡片、编辑、删除、隐私可控文案。

## 镜头 4：个性化行程规划

时间：70 秒；3 分钟版压缩到 40 秒。

操作：进入“行程”。如果页面已有从聊天生成的计划，先展示计划；否则填写：

- 目的地：广州
- 开始/结束日期：周末两天
- 同行人：朋友或自己
- 偏好：夜景、慢节奏、不吃香菜、预算适中
- 预算：适中或偏省
- 交通：步行/公共交通

点击“生成行程”，展示标题、两日安排、画像匹配解释、风险提示、备选方案、地图导航、行程参考信息。

旁白：

“行程规划会把刚才确认的记忆、用户输入的目的地和外部工具结果组合起来。喜欢夜景，所以夜间活动会被放到更合适的时段；不想太累，所以路线会减少跨区奔波；不吃香菜和预算偏好也会进入餐饮和推荐解释。真实高德配置可用时，天气、POI 和路线会作为参考信息进入规划。”

屏幕重点：目的地与输入一致、画像匹配解释、天气/地点/路线参考、备选方案、地图导航。

可选补充：点击“修改”或“重规划”，展示天气或体力变化后的动态调整。

## 镜头 5：多人偏好协调

时间：35 秒；3 分钟版可略过或压缩到 15 秒。

操作：在行程页多人协调区域输入：

- 成员 A：想拍照、喜欢夜景、不想走太多路。
- 成员 B：预算低、想吃地道小吃、不要太晚回酒店。

点击“生成折中方案”，展示冲突摘要、折中建议和隐私摘要。

旁白：

“多人出游时，蓝心同行不会简单把每个人的原始偏好都暴露出来，而是提炼冲突和折中结果。这样既能协同行程，也能减少直接公开个人敏感偏好的风险。”

## 镜头 6：主动提醒

时间：45 秒；3 分钟版压缩到 25 秒。

操作：打开“消息”或提醒页，触发天气、状态或拍照提醒之一，展示提醒内容、触发原因和提醒历史。

旁白：

“旅行中，蓝小心不是等用户问才出现。它可以根据天气、时间、位置、照片动作或用户状态给出主动提醒。同时主动程度是可控的，避免变成打扰。”

屏幕重点：拍照触发、状态触发、天气触发按钮之一，提醒卡片，提醒历史。

## 镜头 7：旅拍候选、文案和旅行盲盒

时间：60 秒；3 分钟版压缩到 35 秒。

操作：进入旅拍页。

1. 点击“登记候选”，从相册选择一张可公开照片；或点击相机图标拍摄测试照片。
2. 展示“本地路径不会上传保存”等隐私提示。
3. 点击“生成文案”。
4. 展示朋友圈、小红书、日记、Vlog 旁白文案。
5. 在“旅行盲盒”里点击“接受”，再点击“完成”。
6. 展示好感/默契奖励。

旁白：

“旅拍部分会把用户主动选择的照片变成候选集，再生成不同平台风格的文案。它不会自动发布社交平台，发布前必须由用户确认。旅行盲盒则把旅途中的小任务沉淀为共同经历，完成后会影响蓝小心的状态和复盘素材。”

## 镜头 8：旅行复盘

时间：60 秒；3 分钟版压缩到 35 秒。

操作：进入“复盘”，生成或查看当前复盘，展示路线、高光照片、完成任务、提醒历史、新增记忆、蓝小心状态变化、下次建议。

旁白：

“旅行结束后，蓝心同行会把路线、照片、提醒、盲盒任务和确认过的记忆汇总成复盘。这里的重点是，它只引用已经发生或已经保存的数据。没有真实路线点时不会编造路线；没有照片候选时也不会假装有高光照片。”

屏幕重点：复盘摘要、旅拍数量、记忆数量、完成任务、下次旅行建议。

## 镜头 9：设置、账号与隐私控制

时间：45 秒；3 分钟版压缩到 20 秒。

操作：打开“设置”，展示账号设置、游客/注册/登录、主动程度、人格、语音/文字偏好、开屏动画策略、数据控制入口。

旁白：

“最后是隐私和可控性。用户可以管理账号、主动提醒程度、语音和文字偏好，也可以管理记忆、同步和清空数据。蓝心同行的产品边界是：长期记忆和内容发布都需要用户可见、可控、可撤销。”

## 镜头 10：技术可信与降级边界

时间：35 秒；3 分钟版可只用 10 秒旁白带过。

画面：电脑浏览器打开 `https://api.rxcccccc.icu/docs`，展示 `/api/audit/model-calls` 和 `/api/audit/tool-calls`；或放一张接口返回截图。

旁白：

“为了让演示可信，后端保留模型和工具调用审计。日志只展示 provider、scenario、fallback、错误类型等摘要，不展示密钥或完整敏感原文。真实服务不可用时，系统会明确 fallback，而不是把 Mock 包装成真实能力。”

## 结尾

时间：15 秒。

画面：回到首页，蓝小心和当前旅程同屏。

旁白：

“蓝心同行的核心价值，是把一次旅行变成可记忆、可调整、可复盘的陪伴体验。它不是一次性的攻略生成器，而是会随着用户和旅程持续成长的 AI 旅行搭子。”

## 录制时避免的问题

- 不要展示 `.env`、密钥、Token、云服务器密码或 SSH 私钥。
- 不要展示未经授权的人像、身份证明、详细家庭住址或私人位置轨迹。
- 不要说“已正式发布上线”，当前 APK 仍是 debug signing，适合演示和测试。
- 不要把 `mock`、`fallback=true` 或 `provider=unconfigured` 说成真实模型/真实地图能力。
- 不要在视频中切换太多城市；一条主线只讲一个目的地。
- 不要把尚未接入的手机号短信登录、OAuth、自动发布社交平台描述成已完成能力。

## 录制失败时的兜底讲法

如果云端模型慢或高德失败，可以保留画面并明确说明：

“这里展示的是系统的可信降级边界。真实 Provider 未返回时，页面不会伪装真实数据，而是显示 fallback 或 unconfigured。比赛正式录制前，我们会以 smoke 检查确保模型和高德链路为 fallback=false。”

如果真机网络连不上本地后端，可以切换到公网 APK 或用：

```powershell
adb reverse tcp:8000 tcp:8000
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

如果照片权限临时异常，可以跳过拍照，改用已准备的相册素材，并说明旅拍候选由用户主动选择，不会自动读取所有照片。

# 归档说明

本目录存放比赛期间使用、现已不再活跃维护的文件。保留这些文件作为历史记录，不影响当前项目运行。

## 内容

- `handoff/`：比赛演示、提交清单、验收脚本、视频脚本、PPT 大纲等交接文档。
- `scripts/`：比赛提交就绪检查脚本（submission readiness、demo evidence、package manifest、public submission hygiene）。
- `tests/`：上述脚本对应的测试文件。
- `superpowers/`：早期 Superpowers 工作流计划文档。
- `reference/vivo-aigc/`：vivo AIGC 平台 API 参考文档抓取。
- `api-health-check-report.md`：历史 API 健康检查报告。

## 为何保留

这些文件记录了项目从比赛作品到简历作品的演进过程，可供面试时追溯工程决策背景。如需清理，可整目录删除而不影响运行。

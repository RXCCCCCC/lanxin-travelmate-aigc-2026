# 3 分钟 Demo 脚本

> 目标：展示“蓝心同行”不是普通聊天助手，而是能贯穿旅行前、中、后的个性化 AI 旅行搭子。录制前必须确认真实模型/地图 Key 的联调状态；如果仍使用降级数据，旁白要明确说明当前是降级演示。

## 镜头 0：准备画面，10 秒

画面：手机打开蓝心同行首页，蓝小心处于待机状态。

旁白：

“蓝心同行是一个懂你偏好、能主动陪伴的全旅程 AI 旅行搭子。这个 Demo 会走完从聊天需求、记忆确认、个性化规划、主动提醒、旅拍任务到旅行复盘的完整闭环。”

## 镜头 1：聊天提出需求，30 秒

操作：在聊天页输入：

“周末想去重庆两天，不想太累，喜欢夜景，我不吃香菜。”

展示重点：

- 蓝小心回复。
- `memoryCandidates` 出现夜景、慢节奏、不吃香菜等候选。
- 规划卡、提醒卡或复盘卡出现。
- 如果工具未配置真实 Key，展示 `toolTrace` 中的 fallback/unconfigured 字段。

旁白：

“用户不用填复杂表单，只要自然说出旅行想法。Agent 会识别偏好和约束，并把可能长期影响体验的信息变成待确认的记忆候选。”

## 镜头 2：确认记忆胶囊，25 秒

操作：打开记忆确认入口，将“不吃香菜”保存为长期记忆，将“不想太累”保存为本次旅行记忆。

展示重点：

- 记忆范围：长期、本次、临时、不记忆。
- 记忆页可查看、编辑、删除。
- 敏感/个人信息需要显式确认。

旁白：

“记忆不是偷偷保存。蓝心同行会让用户决定记多久、用在哪，并支持随时编辑或删除。”

## 镜头 3：个性化规划，35 秒

操作：进入规划页，展示两日行程、画像匹配解释、风险提示和备选方案。

展示重点：

- 规划引用夜景、慢节奏、饮食忌口。
- 展示备选方案和导航入口。
- 如果已配置高德 Key，展示真实天气/POI/路线信息；否则说明当前为无 Key 降级。

旁白：

“规划不是固定攻略，而是把用户画像、当前旅程上下文和外部工具结果组合起来。喜欢夜景，所以夜景点放在傍晚后；不想太累，所以路线减少跨区移动；不吃香菜，所以餐饮建议会避开风险。”

## 镜头 4：主动情境提醒，25 秒

操作：打开提醒页，触发一次低精力或天气变化提醒。

展示重点：

- 时间、位置、状态或外部事件触发。
- 冷却时间和主动程度设置。
- 提醒历史可进入复盘。

旁白：

“旅行中，蓝小心不是等用户提问才出现。它可以根据时间、位置、天气、行程节点和状态给出可控的主动提醒，并避免连续打扰。”

## 镜头 5：旅拍与盲盒任务，30 秒

操作：进入旅拍页，展示照片候选、文案生成和盲盒任务；完成一个任务。

展示重点：

- 用户选择或拍摄照片后加入候选集。
- 生成朋友圈、小红书、日记或 Vlog 文案。
- 盲盒任务完成后写入状态奖励和复盘素材。
- 不自动发布社交平台。

旁白：

“蓝心同行还能把旅途中的照片和小任务变成共同经历。所有发布前内容都由用户确认，不会自动发到社交平台。”

## 镜头 6：旅行复盘，35 秒

操作：进入复盘页或调用复盘生成，展示路线、高光照片、新增记忆、完成任务、提醒历史、蓝小心状态变化和下次建议。

展示重点：

- `route` 来自保存的轨迹点。
- `highlightPhotos` 来自可复盘照片候选。
- `completedTasks` 来自完成的盲盒任务。
- `newMemories` 来自本次旅程确认记忆。
- `nextTripSuggestions` 来自路线、照片、提醒和记忆上下文。

旁白：

“旅行结束后，复盘会沉淀真实发生过的路线、照片、提醒、任务和记忆变化。下一次旅行建议也会基于这些上下文生成，而不是固定模板。”

## 镜头 7：审计与可信降级，15 秒

操作：打开 Swagger 或接口调试工具，展示 `/api/audit/tool-calls`、`/api/audit/model-calls`。

展示重点：

- 能追踪工具和模型调用。
- 请求摘要脱敏。
- fallback 原因清晰。

旁白：

“为了让 Demo 可解释，后端提供工具和模型审计日志。真实能力未配置时会明确降级，不伪装真实数据。”

## 结尾，10 秒

画面：回到首页或复盘结尾卡。

旁白：

“蓝心同行的核心价值，是把一次旅行变成可记忆、可调整、可复盘的陪伴体验。它不是一次性攻略生成器，而是会随着用户和旅程持续成长的 AI 旅行搭子。”

## 录制前检查

- 后端服务已启动，`/api/health` 正常。
- 手机端 API 地址正确，真机使用局域网 IP。
- 真实模型和高德 Key 是否已配置，录制旁白与画面保持一致。
- 准备一组真实可展示的目的地、路线点、照片和用户偏好。
- 不展示真实密钥、私人位置、身份证明、未经授权照片或队友隐私。

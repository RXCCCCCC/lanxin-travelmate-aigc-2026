## 执行原则

- 主链路必须使用真实数据、真实接口或真实设备能力；Mock、固定重庆样例、手动模拟按钮只能作为异常降级，不能作为完成验收依据。
- 所有真实 API 仍需保留可控降级路径，避免演示现场因网络或密钥问题完全不可用。
- 人工介入项单独标注；AI 只推进可通过代码、文档、测试和本地配置完成的部分。
- 每完成一项后同步更新本文件、相关文档和必要测试。

## 十一、近期建议执行顺序

1. 先做真实化基础：配置真实 Provider 接口、工具服务接口、数据库持久化和页面去 Mock。
2. 再做端侧能力：定位、照片选择、通知、语音。
3. 然后做产品增强：盲盒完成状态、多人协调、动画素材。
4. 最后做交付：真机 APK、Demo 视频、PPT 和提交包。

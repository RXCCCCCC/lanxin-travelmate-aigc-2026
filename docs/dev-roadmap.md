# 开发路线

## MVP-1：可启动与 Mock 联调

- FastAPI 可启动。
- Swagger 可访问。
- `/api/agent/chat` 返回统一 Mock Agent 响应。
- Flutter 聊天页接入后端，并展示回复、记忆候选和状态变化。

## MVP-2：记忆胶囊与画像

- Agent 从聊天中识别潜在记忆。
- 用户确认记忆范围。
- Drift SQLite 保存本地记忆。
- 记忆页支持查看、编辑和删除。
- 规划说明能引用已识别偏好。

## MVP-3：规划、提醒、状态、复盘闭环

- 规划页展示 Agent 生成的重庆两日路线。
- 主动提醒页展示时间和位置触发 Mock。
- 蓝小心状态随聊天和记忆确认变化。
- 复盘页展示路线、高光照片、新增记忆和状态变化。
- P1 复盘增强：复盘页可独立调用 `/api/trip/review`，展示完成任务、下次旅行建议和临时记忆转长期记忆询问。

## MVP-4：真实能力接入

- 蓝心模型适配器接入真实 API。
- 地图、天气、POI 工具从 Mock 切换到真实服务。
- 引入更完整的同步策略和服务端存储。

## MVP-5：演示打磨

- 稳定 3 分钟 Demo 剧本。
- 强化 PPT 截图和录屏路径。
- 只保留可控、可解释、低权限风险的能力。

## P1 增强记录

- 主动提醒页支持手动模拟拍照行为、低精力状态、天气/排队外部事件触发。
- 设置页展示 5 种蓝小心人格、自定义 Prompt、动作映射和状态表达文案。
- 规划页展示备选方案与高德外部导航入口。
